# Phase 6 — 巻開始位置の自動照合
開始: Phase 1–5の入力・参照DTO。Implementerがpure matching、Reviewerが誤割当リスクを検証。
- 全話のサイト横断mergeは行わず、各巻開始話のみをrenumber順の入力へ対応付ける。同一Piccoma product/source external IDの一致を優先。別siteは保守的な話名正規化（全半角、空白、明確な第N話/#N、分割表記(1)/①/前後編）と本編話数、必要に応じサブタイトル/前後の順序で候補を絞る。既存order_label/DBは変えない。小数・番外編・特典・巻番号・日付を誤って本編話数にしない。
- ピッコマの第30話(1)と他サイトの第30話①〜⑤は、同一話で先頭が一意かつ順序整合する場合のみ最初のpartへ。開始が途中part、先頭part欠損、同じ話数の繰り返し、複数話を一ZIPに含み巻をまたぐ場合、境界候補複数/欠損は手動確認。部分取得を先頭からと推定しない。
- 巻番号と開始位置の単調性、重複、既存巻との衝突、参照範囲を検証。境界間の番外編は前の巻に含まれる。最初の境界前・最終既刊の収録末尾不明/未収録・欠損境界は手動判断。取得済み巻のみの範囲はコピー。手動境界を尊重し再解決で上書きしない。確定できた境界は保持して未解決だけ表示。未解決のまま生成しない。
受入/テスト: 分割数差、前後編、全半角、同名/巻内再採番、特典/小数、異site混在、欠損開始、巻途中、境界逆転/重複、手動保持、途中巻開始、既存巻重複、未収録末尾。人工fixtureの期待値と手動正解の比較で誤自動確定0。BLOCKING-0でPhase 7へ。
