# 書籍ファイル命名規則

## 1. 目的

漫画・小説・技術書・雑誌などの電子書籍について、ファイル名を統一し、一覧表示・検索・並び替え・将来の自動処理をしやすくする。

基本方針は以下とする。

- タイトルを先頭にする
- 区切り文字は半角ハイフン `-`
- ハイフンの前後に空白を入れない
- 巻数・話数など、並び順に関係する情報をタイトルの直後に置く
- 存在しない項目は省略する
- ジャンルはファイル名に含めず、フォルダで分類する
- 通常ケースを優先し、特殊なケースのために命名を過度に複雑化しない

---

## 2. 基本形式

```text
タイトル-順序情報-作者名-版情報.ext
```

すべての項目を必須とはしない。

必要な情報だけを、以下の順番で記載する。

```text
タイトル
↓
巻数・話数・年月・号数など
↓
作者名
↓
版情報
```

### 例

```text
キングダム-第01巻-原泰久.zip
容疑者Xの献身-東野圭吾.epub
達人プログラマー-DavidThomas・AndrewHunt-第2版.epub
SoftwareDesign-2026-09.pdf
```

---

## 3. 漫画

基本形式：

```text
作品名-第01巻-作者名.ext
```

例：

```text
キングダム-第01巻-原泰久.zip
キングダム-第02巻-原泰久.zip
キングダム-第10巻-原泰久.zip
```

### 巻数

巻数は原則として **2桁のゼロ埋め** とする。

```text
第01巻
第02巻
第09巻
第10巻
第99巻
```

100巻未満の作品では、2桁表記を標準とする。

### 100巻以上の作品

100巻以上存在する作品では、その作品に限って **3桁のゼロ埋め** に統一する。

```text
第001巻
第002巻
第099巻
第100巻
```

連載途中で100巻に到達した場合は、その時点で既存巻も含めて3桁表記へ一括変更する。

```text
変更前
作品名-第01巻-作者名.zip
作品名-第99巻-作者名.zip

変更後
作品名-第001巻-作者名.zip
作品名-第099巻-作者名.zip
作品名-第100巻-作者名.zip
```

同一作品内で2桁表記と3桁表記を混在させない。

### Manga ONEなど話数単位の配信

話単位で配信される漫画は、巻数ではなく話数を順序情報にする。
話数は2桁以上のゼロ埋めとし、前編・後編は別ファイルとして保持する。

```text
作品名-第01話.zip
作品名-第01話-前編.zip
作品名-第01話-後編.zip
作品名-第10話.zip
作品名-第100話.zip
```

前編・後編の統合、および話数から巻数への変換は後工程で行う。配信元から
前編・後編の情報が取得できない場合は、話数だけを付ける。

---

## 4. 小説

### 単巻作品

```text
作品名-作者名.ext
```

例：

```text
容疑者Xの献身-東野圭吾.epub
吾輩は猫である-夏目漱石.epub
```

### シリーズ作品

```text
作品名-第01巻-作者名.ext
```

例：

```text
銀河英雄伝説-第01巻-田中芳樹.epub
銀河英雄伝説-第02巻-田中芳樹.epub
```

巻数表記は漫画と同じルールを使用する。

---

## 5. 技術書・実用書

基本形式：

```text
書名-作者名.ext
```

版がある場合：

```text
書名-作者名-第2版.ext
```

例：

```text
達人プログラマー-DavidThomas・AndrewHunt-第2版.epub
EffectiveJava-JoshuaBloch-第3版.pdf
```

複数著者の場合は `・` で区切る。

```text
書名-山田太郎・鈴木一郎.pdf
```

著者が非常に多い場合は、必要に応じて代表著者のみとする。

---

## 6. 雑誌

雑誌は巻数ではなく発行年月を基本とする。

```text
雑誌名-YYYY-MM.ext
```

例：

```text
SoftwareDesign-2026-01.pdf
SoftwareDesign-2026-02.pdf
SoftwareDesign-2026-09.pdf
```

号数も必要な場合：

```text
雑誌名-YYYY-MM-No.001.ext
```

例：

```text
SoftwareDesign-2026-09-No.485.pdf
```

年月を `YYYY-MM` とすることで、年月順に自然に並ぶようにする。

---

## 7. 完全版・新装版など

通常とは異なるシリーズや形態であることを明確にしたい場合は、タイトル直後に角括弧 `[]` で記載する。

```text
作品名[完全版]-第01巻-作者名.ext
作品名[新装版]-第01巻-作者名.ext
```

例：

```text
AKIRA[フルカラー版]-第01巻-大友克洋.zip
SLAMDUNK[新装再編版]-第01巻-井上雄彦.zip
```

使用例：

```text
[完全版]
[新装版]
[新装再編版]
[文庫版]
[フルカラー版]
[青空文庫]
```

同じ作品の別バージョンを区別する必要がない場合は付けなくてよい。

---

## 8. 作者名

日本人名は原則として空白を入れない。

```text
原泰久
東野圭吾
夏目漱石
```

外国人名についても、ファイル名上では原則として空白を省略する。

```text
JoshuaBloch
DavidThomas
```

複数著者の場合は `・` で区切る。

```text
DavidThomas・AndrewHunt
```

---

## 9. フォルダ構成

ジャンルはファイル名には入れず、フォルダ側で分類する。

例：

```text
Books/
├─漫画/
├─小説/
├─技術書/
└─雑誌/
```

必要に応じて、さらに作品単位・作者単位のフォルダを作ってよい。

例：

```text
漫画/
└─キングダム/
   ├─キングダム-第01巻-原泰久.zip
   ├─キングダム-第02巻-原泰久.zip
   └─キングダム-第03巻-原泰久.zip
```

フォルダ構成にかかわらず、ファイル名自体は本規則に従う。

---

## 10. 使用しない文字

Windows等で問題になりやすいため、以下の文字はファイル名では使用しない。

```text
\ / : * ? " < > |
```

書名にこれらが含まれる場合は、安全な文字に置換または省略する。

例：

```text
A/Bテスト
↓
A・Bテスト
```

---

## 11. 基本ルールまとめ

命名順序：

```text
タイトル-順序情報-作者名-版情報.ext
```

代表例：

```text
キングダム-第01巻-原泰久.zip
容疑者Xの献身-東野圭吾.epub
銀河英雄伝説-第01巻-田中芳樹.epub
EffectiveJava-JoshuaBloch-第3版.pdf
SoftwareDesign-2026-09.pdf
SLAMDUNK[新装再編版]-第01巻-井上雄彦.zip
```

原則：

- タイトルを先頭にする
- 区切りは半角ハイフン `-`
- ハイフン前後に空白を入れない
- 巻数は原則2桁ゼロ埋め
- 話数は原則2桁ゼロ埋め。前編・後編は話数の後ろに付ける
- 100巻以上の作品のみ、その作品全体を3桁ゼロ埋めに統一する
- 同一作品内で2桁と3桁を混在させない
- 雑誌年月は `YYYY-MM`
- 特殊版は `[ ]`
- 作者名には原則空白を入れない
- ジャンルはフォルダで管理する
- ファイル名として使用できない文字は置換する
