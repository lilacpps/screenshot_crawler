## Implemented rule

`native_capture.py` retains the existing 280x400 geometry path and adds only
the observed 720x1024 frame with 16 176x256 tiles covering 704x1024. The new
layout is restricted to baseline 8-bit grayscale 1x1 sampling. Provenance,
all-or-none spread behavior, source marker/metadata normalization, DCT
readback, untouched-edge, and the 2,000,000-byte limit remain unchanged.
Color, subsampled, progressive, malformed, incomplete, dimension-mismatched,
or non-8px-aligned inputs remain PNG fallback candidates.

Classification: **C — safely extendable**, bounded to this proven layout.
